# Supabase migrations

Applied against the `handyhail` Supabase project (`vogzjkdotepgrqcdabmu`), which
backs At Your Service.

The migrations numbered before `20260829200941` were applied while the app was
first built and are not reproduced here — this directory starts at the Phase 1
(trust & safety) work. Each file name matches the `version`/`name` recorded in
Supabase's `supabase_migrations.schema_migrations` table, so the two can be
reconciled with `list_migrations`.
